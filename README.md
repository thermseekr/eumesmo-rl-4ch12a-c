# eumesmo-rl-4ch12a-c

Relay board with 4x 24 VDC Form C (NO + NC) relays. This board is designed to be used togheter with [eumesmo-io-24v16ch](https://github.com/thermseekr/eumesmo-io-24v16ch), but can be driven by any 24V control circuit compatible with NPN inputs. It uses 16A relays and is limited to 12A/channel per copper trace capacity.

The board is compatible with the SP7 DIN rail system from Metaltex.

![eumesmo-rl-4ch12a-c](https://github.com/thermseekr/relay-24v-4ch-12a-nc/blob/main/V1/eumesmo-rl-4ch12a-c-v1.3.png)
